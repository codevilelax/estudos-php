# Estudos de PHP

Meus estudos de PHP, do zero, com exercícios práticos.

## Estrutura

| Pasta | Assunto |
| --- | --- |
| `01-fundamentos` | variáveis, arrays, condicionais, loops, funções |
| `02-web` | formulários, GET/POST, sessões |
| `03-banco-de-dados` | MySQL, PDO |
| `04-poo` | classes, objetos, herança |
| `05-composer` | pacotes e autoload |
| `06-laravel` | framework Laravel |
| `projetos` | projetos práticos |

Cada exercício fica em um arquivo numerado, com o enunciado em comentário no topo
(ex: `01-fundamentos/ex02-compras.php`).

Os resumos do que já pratiquei ficam junto dos exercícios do assunto
(ex: [resumo do `while`](01-fundamentos/resumo-while.md)).

## Como rodar

```bash
php 01-fundamentos/ex02-compras.php
```

O andamento dos estudos fica em [PROGRESSO.md](PROGRESSO.md).
